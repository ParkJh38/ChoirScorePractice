# PDF viewer validation

## Automated verification

```sh
./gradlew :core:test :app:assembleDebug :app:lintDebug
./gradlew :app:connectedDebugAndroidTest
```

The API 35 emulator suite uses synthetic PDFs generated by the test-only provider (three pages and 24 pages, alternating portrait/landscape geometry and distinct colored marks). It covers:

- Picker selection and opening the viewer, then returning without changing Korean pronunciation.
- Real PdfRenderer raster content at distant pages, vertical list navigation, and bounded bitmap dimensions.
- A small attached-row count instead of attaching all 24 pages.
- Zooming to 150%, horizontal pan, fit-width reset, and page/zoom/document retention across Activity recreation.
- Extreme page aspect ratios staying within the pixel/dimension allocation limits.
- Unavailable documents showing recovery with zoom disabled.
- Persistable permission and URI restoration in a fresh input Activity/ViewModel session, then revoked-permission recovery.
- All previous TXT, Korean clipboard/editing, cancellation, and invalid-input regression checks.

This is not a native-memory benchmark, exhaustive PDF compatibility test, or proof of Galaxy performance.

## System picker smoke test

1. Put a permitted multi-page PDF in the emulator Downloads directory.
2. Select it through **Select PDF score**, then tap **View PDF score**.
3. Check visible page content, swipe vertically across page boundaries, use **Zoom in**, pan sideways, and return to **Fit width**.
4. Rotate the device and verify the same document remains viewable.
5. Go back and verify existing TXT/pronunciation input remains unchanged.
6. When the UI reports persistent access, stop/relaunch the app and verify the filename returns and the viewer opens without reselection.
7. Move/delete the original PDF or revoke its provider permission; verify recovery by selecting another file.

## Limits

- Zoom uses buttons (100%, 150%, 200%, 300%); no pinch gesture or high-resolution tile renderer yet.
- A page raster is capped at 2 million pixels / 4096 pixels per side. Large scores may look softer when enlarged. Native PDF parsing memory is outside this bitmap budget.
- Password-protected and non-seekable provider documents are unsupported. Unavailable/corrupt files show an error, and individual render failures can be retried.
- Persistence retains only the last document URI when a provider grants read persistence. Moving/deleting the original file can invalidate it; no permanent PDF copy is made.
- Pronunciation remains session-only. No OMR, text selection/search, annotations, or piano playback is implemented.
- API 26, physical Galaxy devices, TalkBack score-content access, and full large-font/landscape layout coverage remain unverified.
